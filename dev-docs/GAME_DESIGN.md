# 微光农庄 · Vale Farm —— 游戏设定速查

> 改数值 / 加内容前先看这里；改了代码记得同步这份文档。
> 所有数值的**唯一数据源**在 `src/core/config.ts`（全局常量）和 `src/core/data.ts`（作物 / NPC），这里只做索引与解释。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| 中文名 | **微光农庄** |
| 英文名 | **Vale Farm**（vale = 山谷，暗合 NPC 台词「有你在，这山谷都热闹起来了」） |
| 类型 | 2D 像素风农场生活模拟（种—浇—收—卖—送礼循环） |
| 技术 | Phaser 3.80 + TypeScript + Vite，纯前端静态部署，PWA 可离线 |
| 平台 | 手机优先（横屏 / 竖屏自适应），桌面可玩（方向键 + 空格） |
| 素材 | 全部程序生成（`tools/gen_assets.py`），原创，无第三方素材 |

## 2. 世界与地图

- 大地图 **40×16** 格，每格 **32px**（`MAP_W/H`、`TILE_PX`）
- 可耕种农田 **12×10**，位于地图左上角偏移 `(3, 5)`（`FARM_W/H/OX/OY`）
- 关键地点（tile 坐标）：
  - 小屋 / 床：`(2, 2)` —— 走到面前按「互动」睡觉
  - 种子商店：`(19, 2)` —— 营业时间 **7:00–22:00**
  - 出货箱：`(15, 4)` —— 卖作物（路南侧，避免挡住道路）
  - NPC 米拉：`(18, 4)`
  - **村庄广场**：`x=16..23, y=4..7`，含水井 `(21,5)`、长椅 `(17,6)/(20,6)`、路灯 `(16,4)/(23,4)`、木牌 `(16,5)`、第二栋小屋 `(23,1)`
  - **林区**：`x=24..39`，从商店门口沿路向东；12 棵固定树，砍 3 下倒，给 2 木头
  - **矿脉**：林区北侧岩壁一线 4 处（`ORE_SPOTS`：`(25,1) (29,1) (33,1) (37,2)`）

## 3. 时间与季节

| 项 | 数值 |
|---|---|
| 1 游戏分钟 | 350ms 真实时间（`MS_PER_GAME_MINUTE`） |
| 一天 | 6:00 起床 → 次日 2:00 强制昏倒，约 **7 分钟现实时间** |
| 一季 | **28 天**，四季：春 / 夏 / 秋 / 冬（`SEASON_DAYS`、`SEASON_NAMES`） |
| 天气 | 晴 / 雨，雨天概率 **25%**（`RAIN_CHANCE`）；雨天作物自动浇水 |

## 6.5 林区、矿脉与制作台

- 林区从商店门口沿道路向东，树木点位固定（`TREE_SPOTS`）。
- 每棵树 3 下砍倒，每下 4 体力；倒后获得 2 木头（`TREE_HP/TREE_WOOD`）。
- **矿脉**：林区北侧岩壁一线 4 处，点位固定（`ORE_SPOTS`）。
  - 需要背包里有**木镐子**（`tool:pickaxe`），否则互动只提示、不扣体力。
  - 每处 3 下挖空，每下 **6 体力**；每下 1 铜矿石，**挖空那一下额外 1 铁矿石**（`ORE_HP/ORE_COPPER_PER_HIT/ORE_IRON_BONUS`）。
  - 挖空当天不再阻挡、不再产出，**次日清晨全部回满**（`refreshOres`，每日结算里调用）。
- **矿石收购价**（`ORE_SELL`，出货箱与杂货铺"出售"页同源）：铜矿石 22G / 铁矿石 58G。
- 物品栏：☰ → 系统 → 物品栏，分种子 / 材料 / 作物 / 工具（材料含木头与两种矿石）。
- 制作台：☰ → 系统 → 制作台；木镐子配方 = 3 木头，工具唯一。
- 本期做的是"露天矿脉"，**独立矿洞场景尚未实现**（需要第二张地图与场景切换，等有可视化验收环境再做）。

## 6.6 装饰（`data.ts → DECORS`）

摆在自己农场里的可购买物件。**不占农田**（农田格不能摆），收回永远允许。

| 装饰 | id | 价格 | 是否挡路 |
|---|---|---|---|
| 木栅栏段 | `decor:fence` | 40G | 挡 |
| 陶土花盆 | `decor:flowerpot` | 60G | 挡 |
| 野餐布 | `decor:rug` | 70G | **不挡**（可踩） |
| 小邮箱 | `decor:mailbox` | 90G | 挡 |
| 石灯笼 | `decor:stonelantern` | 150G | 挡 |
| 稻草人 | `decor:scarecrow` | 220G | 挡 |

- 经济定位：**收成 → 装饰**，给"钱花到哪"一个非扩张的出口（价格按"卖 1~4 次收成买一件"定）。
- 摆放规则（core 侧）：地图内、非农田、单格不重复；树/矿脉/建筑/水面等场景阻挡由 `GameScene` 额外判一次。
- 存档：`World.decor = [{ id, x, y }]`，读档按 `DECORS` 白名单 + 地图范围 + 不重复占格过滤。

## 7. NPC 与好感（`data.ts → NPCS`）

当前 NPC：**米拉**（mira），紫色名牌，种子铺旁。

| 项 | 数值 |
|---|---|
| 每日首次对话 | 好感 +2（`FRIEND_TALK`） |
| 送普通作物 | +30（`GIFT_NORMAL`） |
| 送最爱（糖荚豌豆） | +80（`GIFT_LOVED`） |
| 送枯萎作物 | −10（`GIFT_WITHERED`） |

**里程碑奖励**：好感 100 → 萝卜种子 ×10；好感 300 → **500G**。
台词分三档（陌生 / 熟悉 / 亲密），随好感档位切换；同一天同一句，跨天轮换下一句。

> 加新 NPC：在 `NPCS` 数组里加一份定义即可（站位、最爱礼物、奖励、台词），渲染与送礼逻辑通用。

## 8. 操作方式

| 平台 | 操作 |
|---|---|
| 手机 | 左下**摇杆**移动；右下**「互动」**按钮（自动识别锄地 / 播种 / 浇水 / 收获 / 对话 / 开门）；互动键左侧**快捷栏**（点开切换种子/木头/木镐，种子决定播种）；右上 **☰** 系统菜单 |
| 桌面 | 方向键移动，空格 = 互动 |

## 9. 存档

- 位置：IndexedDB `vale-farm`（key `save`），设置项在 localStorage `vale-farm.settings`
- 格式号 `SAVE_FMT = 4`：v1→v2 新增林区树木；v2→v3 新增矿脉与矿石物品；v3→v4 新增可摆放装饰（`World.decor` + `decor:<id>` 物品），旧档缺 `decor` 时回落空数组。
- 系统面板支持导出 / 导入 JSON
